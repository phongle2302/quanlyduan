# Database - Hệ thống Quản lý Hợp đồng/Hồ sơ Thư viện

MySQL.

## Cấu trúc thư mục

```
database/
├── schema/       # File mô tả cấu trúc bảng (DDL), ERD
├── migrations/   # Các file migration theo thời gian
└── seeds/        # Dữ liệu mẫu để phát triển/test
```

> Hiện tại chỉ tạo khung thư mục, thiết kế bảng sẽ được bổ sung sau.
